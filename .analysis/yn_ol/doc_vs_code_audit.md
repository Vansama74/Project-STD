| 写失败降级 | — | 返回 `false` → 运行态仍生效、仅告警 `persist FAILED (runtime only)`（`cmd.c:614-635`） | ✓ 不阻塞不重启 |
| 生效范围 | 文档未写 | 后续 `'3'`/`'4'`/行清除的行高与字形（`cmd.c:241/359/377` 等） | ✓ |

### 4.11 `0x01` 全屏点亮颜色映射

- 文档：DATA0 `01` 红 / `02` 绿 / `03` 黄。
- 实现：`declared==1 && 1 ≤ data[0] ≤ 7`（`parse.c:283-286`） → `dev_display_fill(…, (display_color_t)color)`（`cmd.c:474`）。
- `display_color_t` 枚举：`COLOR_BLACK=0, COLOR_RED=1, COLOR_GREEN=2, COLOR_YELLOW=3, COLOR_BLUE=4, COLOR_PURPLE=5, COLOR_CYAN=6, COLOR_WHITE=7` → **01/02/03 与文档恒等** ✓；04~07 为超集 → §5.2 E。

### 4.12 `0x02` 版本号应答与屏显

- 文档：`7B 02 01 00 7D`；返回值 = 屏上显示 = `YN_ZCP_P10_3.0`。
- 实现（`cmd.c:638-678`）：
  1. `channel_send(ch, (uint8_t *)PROGRAM_CODE, sizeof(PROGRAM_CODE)-1)` → **裸 ASCII，无帧封装**（与文档"返回值"形态一致）；
  2. 屏显 `snprintf("版本:%s", PROGRAM_CODE)`，FONT_SELF_ADAPT / 红字 / 居中 / `FONT_ENC_UTF8`。
- 参数校验：`declared==1`（**不校验 data[0] 是否为 0x00**，`parse.c:291-298`）。
- **内容偏离**（`YN_ZCP_P10_3.0` → `PROGRAM_CODE`）→ §5.2 E；格式与"屏上显示"要求一致 ✓。

### 4.13 帧层与命令字重叠/歧义

| 检查项 | 事实 |

## 6. 结论

### 6.1 一句话回答

**YN_1.3.0 尚未「完全实现」，但缺口不是代码漏做，而是文档自身留白**：文档要求实现的 19 条命令（`'1'`~`'5'`、`'8'`、`'A'`、`0x42`~`0x46`、`0x50`、`0x47`~`0x49`、`0x01`、`0x02` 及 `0x48→0x51` 应答）**已全部落地并可逐字段对账**；文档明示不开发的 `'6'`/`'7'`/`'9'` 已在 probe 层快拒；**唯一未落地的是 `'2'` 自检里的「固定汉字信息」，而文档没有给出这段文案 → 属规格缺失，需要向协议提出方索取后才能补**。

### 6.2 未实现 / 待裁决清单（按优先级）

| 优先级 | 项 | 类型 | 需要的动作 |
|---|---|---|---|
| **P1** | `'2'` 自检的「固定汉字信息」文案 | ①真缺口（规格缺失） | **向协议提出方索取文案** → 拿到后补实现 |
| **P2** | `'4'` 的 **0x0D 是否应换行** | ②有意偏离（无独立裁决） | **抓包确认上位机换行符**；若用纯 CR 则需一行改动（须用户拍板） |
| **P3** | `'1'` **异常应答**是否需实现 | ②有意偏离（无独立裁决） | 确认是否需要；`doc/15 §2` 建议补登 |
| **P4** | `'8'` 亮度 `'5'` 非最亮 | ②有意偏离（已裁决维持） | 现场确认观感；如需改为 1:1 线性映射再议 |
