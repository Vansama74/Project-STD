## ① 选中：链 128 位 + 块栅格 4×2 + 块列反向 + 落点 `(3-i%4,(i/4+2)%4)` —— **dA=0, dB=0**

```

  bc = 3-(c%4), br = c/4；dx = 3-(i%4), dy = ((i//4)+2)%4
  (X,Y) = (4*bc+dx, 4*br+dy)
```
