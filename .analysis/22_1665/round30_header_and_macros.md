## 3. 几何宏写法：`#ifndef` → 普通 `#define`

```c
/* 改动前（可 -D 覆盖，但让几何口径「两处真源」） */           /* 改动后（兄弟驱动同款） */
#ifndef _22_1665_MODULE_ROWS                                  #define _22_1665_MODULE_ROWS      (1U)
#define _22_1665_MODULE_ROWS (1U)                             #define _22_1665_MODULE_COLS      (5U)
#endif                                                        #define _22_1665_MODULE_PIXEL_ROW (16U)
...                                                          #define _22_1665_MODULE_PIXEL_COL (16U)
```

- **副作用**：`-D_22_1665_MODULE_*=…` 不再生效（只剩「重定义告警 + **文件值胜出**」）⇒ 换几何口径**必须改文件**；
  宿主脚本一律走 **`macro_override.py` 源码替换**（把源码里那行 `#define` 的值替换掉、生成临时副本再编译）。
- **未动**：`_22_1665_CHAIN_HEAD_IS_MODULE0` 仍是 `#ifndef` 守卫 + 可 `-D`（现场 A/B 唯一旋钮）。
- **为什么不能靠脚本迁就**：`-D` 覆盖在「文件也是普通 `#define`」时会**静默赢错一方**（文件值胜出），
  测出来的口径与预期不符却不报错——这正是必须改成源码替换的原因。
