### 1.2 选择理由：保留「≤ 64KB」物理守卫，而不是全删交给链接器

**选择 = 保留一条 64KB 区域守卫**（用户给出的推荐之一）。理由：

| 维度 | 保留 64KB 守卫（选定） | 全删、只靠链接器 |
|---|---|---|
| 报错可读性 | 编译该 TU 时即给出 ASCII 消息 + 指向「改哪两个宏」；范围明确 | 只在**链接期**报 `region .ccmram overflowed by N bytes`；不指认旋钮；且极端几何（如 ROWS=900）会先在数组声明处抛出更难读的错误 |
| 单一真源 | 该守卫**不编码任何项目预算**：其他消费者 35836B / 整片 64KB 的占用**单 TU 不可知**，整片占用的唯一权威仍是链接器 ⇒ 没有「第二个预算」 | 唯一真源最纯粹，但把「本模组单独都已超整片」这种一眼可判的错推迟到链接 |
| 语义归类 | 64KB 是**芯片事实**（STM32F407 CCM 64KB = 链接脚本 `CCMRAM LENGTH = 64K`），与 uint8/uint16 宽度守卫同类，属「物理守卫」 | — |

即：**删掉的是「自设预算」，保留的是「物理事实守卫」**；两条路的差异只在报错时机与可读性，
`check_driver.py` 新增断言同时锚定「新守卫存在」+「旧 `16384` / `budget exceeded` 零残留」，
防止有人再把预算塞回来。

## 2. 「宏仍是唯一旋钮」确认

- 驱动内**几何只由 `_22_1665_MODULE_ROWS` / `_22_1665_MODULE_COLS` 决定**：链段数 `4M`、每帧时钟
  `128 × ROWS`、组数 `= COLS`、链段落点表 `[4M][128]`、状态数组 `[128M]`、像素表 `[256M]`、
  合并写表 `[COLS][2][16]` 全部派生；**数据线表恒 5 组 × 4 行，不补表**。
- **8×2 现状下 `make DISP=22_1665 -j8` 编过**（见 §3），且除 CCM 占用外的所有断言均为类型/派生/物理守卫，
  与分辨率无关。
- 唯一与「规模」有关的守卫现在只有两条，且都**不是**项目预算：`2 × MODULE_COLS ≤ HUB75_CHANNEL_MAX = 10`
  （HUB75 通道/引脚物理事实）与 `CCM_BYTES ≤ 64KB`（整片 CCMRAM 区域，芯片事实）。
- 宿主侧「换口径」机制不变：几何宏是普通 `#define`，`-D` 不生效；换口径走
  `macro_override.py` 源码替换（`link_variant.sh` 几何参数写 `宏名=值`）。

## 5. 物理 / 类型约束（哪些保留、哪一条被删）

| 类别 | 内容 | 是否人为上限 |
|---|---|---|
| **物理（保留）** | `2 × MODULE_COLS ≤ HUB75_CHANNEL_MAX = 10`（⇒ COLS ≤ 5；HUB75 通道与引脚物理事实） | 否 |
| **物理（保留）** | 每组 4 条数据线（`LINE_COUNT == 4` = R/G × 上/下半屏）、数据线表恒 5 组 × 4 行 | 否 |
| **物理（保留，本轮新形态）** | `_22_1665_CCM_BYTES ≤ 64KB` = 整片 CCMRAM 区域（芯片事实 / 链接脚本 `LENGTH = 64K`） | 否（**替代**旧的自设 16KB） |
| **类型宽度（保留）** | 像素数 ≤65535（`chain_dst` 偏移类型）、帧位数 ≤65535（scan 上界）、状态数 ≤256、模块数 ≤255（基类 `uint8_t` 字段） | 否 |
| **派生一致性（保留）** | 单模块恰 8 块 = 128 位 = 256 像素、链段数 = 4×M、状态数组 = 组数 × 每帧时钟数、数据线表形状 | 否 |
| **性能（非编译期，须上机复核）** | 8×2：`scan` ≈0.36~0.48ms（占 TIM3 固定 500µs 周期的 72%~96%）；`prepare` 整帧提交 ≈1.0~1.2ms（跨帧掉帧） | 否（但**用户须知情**） |
| ~~**自设预算（本轮删除）**~~ | ~~`_22_1665_CCM_BYTES ≤ 16384U`（16KB）~~ | **是 → 已删** |

**若 8×2 实测超标，可选方向（本轮均未做）**：
① 增大 TIM3 周期以降刷新率（**本轮禁止改定时参数**，属产品口径决策）；
② 后续按需把 `chain_dst` 全量预计算表（1024·M，M=16 时为 16384B）降级为「按需计算 + 小块常量表」
