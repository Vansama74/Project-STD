## §1 协议事实

### 1.1 帧格式

```
偏移  字段          长度   说明
0     0xAA          1      引导码 1
1     address       1      1~255（255 = 广播）；本工程 v1 不判
2     0xBB          1      引导码 2
3     cmd1          1      命令码高字节
4     cmd2          1      命令码低字节
5     数据累加和     1      仅 51 54 有：= [6..结束码前] 逐字节累加取低 8 位；本工程 v1 不校验
6..   data          变长   命令相关
末    0xFF          1      结束码（51 54 / 56 4F / 03 03 有；其余定长命令无）
```

- **无长度字段**：`51 54` 靠扫描 `0xFF` 定界；其余命令靠「命令码 + 固定长度」定界。
- 串口 8N1，波特率由 **DIP1 全局选择**（OFF = 9600，ON = 115200），模块内不改波特率。

### 1.2 命令表（8 组命令码 / 10 条逻辑命令）

| cmd1 cmd2 | 逻辑命令 | 整帧长 | 关键字段 | 应答 |
|---|---|---|---|---|
| `51 54` | 显示文本 | 12~204（`0xFF` 定界） | [6] 播放方式 1~21 / [7] 速度 / [8] 停留 / [9] 颜色 0/1/2 / [10] 总显示时间（秒）/ [11..] GBK 文本 ≤192B | `0x1B` |
| `4B 4C` | 亮度 | 7 | [5] 亮度 0~3（0 最亮）；[6] 同值，忽略 | `0x1B` |
| `4B 5A` | 车道灯/报警器 | 8 | [5..7] 六种固定三元组 | `0x1B` |
| `56 4F 00` | 礼貌语 | 8 | [6] 编号 1~5 | `0x1B` |
| `56 4F 01` | 收费语音 | 14 | [6..12] 七位 ASCII 金额（万/千/百/十/个/十分/百分） | `0x1B` |
| `01 01` | 全屏点亮 | 7 | [5] = [6] = 0 红 / 1 绿 / 2 黄；`03` 丢弃 | 不回 |
| `02 02` | 版本号 | 5 | 无载荷 | 不回 |
| `03 03` | 设置开机界面 | 103 | [5] 颜色 + [6..101] 96B（6 行 × 16B，0x20 补全）+ [102] `0xFF` | `0x1B` |
| `04 04` | 字体/字号 | 6 | [5] 低 4 位字号 0/1/2 → 16/24/32；高 4 位字型 0/1/2/3 → 宋/仿宋/楷/黑 | 不回 |

**车道灯六种三元组（`4B 5A` 的 `[5][6][7]`）**

| 三元组 | 含义 | 本工程动作 |
|---|---|---|
| `FF 00 FF` | 通行绿灯亮 | `dev_io_lane_light(true)` |
| `00 00 00` | 通行绿灯灭（= 红灯亮） | `dev_io_lane_light(false)` |

| `01 02 FF` | 报警（黄闪）开 | `dev_io_flash_light(true)` |
| `02 02 00` | 报警（黄闪）关 | `dev_io_flash_light(false)` |

## §2 已裁决事项与实现

### 2.1 通道与 RB

- 绑定 `CH_ID_RS485` + `CH_ID_RS232`，**两个独立 mask**、同一个 probe、同一个静态队列；
  `0x1B` 用 `frame_msg_t::ch` 原路回送（`channel_send`）。
- **自备两槽槽体**：`RB_PROVIDE_WEAK(rb_provide_rs485, RB_SIZE_RS485)` /
  `RB_PROVIDE_WEAK(rb_provide_rs232, RB_SIZE_RS232)` + `app_proto_acquire_buf`。
  单协议目标下若只 acquire 不 provide，两槽都为空 → 模块静默不注册、串口通道被门控跳过 →
  上位机发帧零反应（2026-10-12 新疆轮的现场教训）。多协议共存构建下同名 weak 符号合并，
  不额外占 SRAM。
- 禁止绑定 `CH_ID_RS232_1`（USART6 语音 TX）。

### 2.2 注册与任务

五步注册（`doc/08_协议模块接入规则/01_通用规则与模块骨架.md` §2）：两槽 acquire →
每槽独立 `app_proto_register` + `app_proto_bind_channel` → 两 mask 共用一静态队列 →
`osThreadNew`（`PL_TASK_STATIC_STORAGE(gx_handle, 256)`、`osPriorityNormal`）。
任一槽取不到即跳过该槽；两槽皆不可用则不建队列/任务。

### 2.3 `51 54` 显示

- 文本上限 **192B**，帧上限 **204B**；`parse` 再校验一次 `0xFF` 结束码。
- 文本先做**换行归一**再交给 `app_render`：
  - `0x0A` 保留（换行）；
  - `0x0D` 丢弃（`0A 0D` 对 → `0A`）；
  - 字面 `\n`（`0x5C 0x6E`）→ `0x0A`，**GBK 边界感知**：先按 GBK 首/尾字节整字拷贝，
    GBK 尾字节 `0x5C` 不会被误判；
  - **不支持 `_`（0x5F）作换行**。
- 渲染参数：`app_render(RENDER_TEXT)`、`FONT_ENC_GBK`、`x=0 / y=0 / w=屏宽 / h=屏高`、
  `word_wrap=true`、左对齐；字号/字型取模块状态（默认 `FONT_16` / `FONT_ST`，可由 `04 04` 改）。
- 「清屏 + 渲染 + 提交」整段持 `app_scroll_render_lock()`（与滚动显示串行）。
- 空文本帧（12B）只清屏。
- 颜色码 0/1/2 → `display_color_t` 红/绿/黄（枚举值 = 码 + 1）。

### 2.4 总显示时间

- `[10]` 单位秒；`0` = 永久（不启动计时）。
- 非 0：记录到期 tick；处理任务每 **`GX_TICK_MS = 500ms`** 的队列等待节拍调用
  `gx_display_timer_tick()`，到期清屏并恢复开机画面——本上电周期内收到过 `03 03` 则恢复该界面，
  从未收到则恢复**项目通用默认画面**「欢迎行驶 / 高速公路」（`app_default_display_show()`，
  即 `app_default_display.c` 的兜底欢迎画面）。**不新建任务**。
- 其它绘制命令（`01 01` / `02 02` / `03 03` / `04 04`）会取消计时，避免旧计时擦掉新内容。

### 2.5 亮度 / 灯 / 语音

- 亮度：`0/1/2/3 → 8/6/4/2`（`DEV_DISPLAY_BRIGHTNESS_MAX = 8`），并 `osThreadSuspend`
  光敏任务（只挂起一次）。协议无「恢复自动」命令，直到重启才恢复（与旧固件一致）。
- 灯：`dev_io_lane_light`（PD14，单红/绿通行灯）+ `dev_io_flash_light`（PD15，报警/黄闪）。
- 语音：`dev_rs232_voice_play()`（USART6 旁路，帧 `FD 00 len 01 01 + GBK`，与旧固件同格式）。
  - 礼貌语 1~5：`您好,欢迎光临` / `您好,免费车` / `谢谢合作,祝您一路平安` / `请出示通行卡` / `再见`。
  - 收费语音：`您好,请交费 X 元`；金额按「分」格式化（`%lu.%02u`，分为 0 只念整数）；
    金额全 0 不播、只回 `0x1B`。
  - 不设置音量（协议无音量命令，沿用语音板上次档位）。

### 2.6 版本 / 全屏 / 开机界面 / 字体

| 命令 | 动作 | 应答 |
|---|---|---|
| `02 02` | 清屏 + 整屏红字 `版本:PROGRAM_CODE`（`FONT_16` / `FONT_ST`，word_wrap） | 不回 |
| `01 01` | 整屏纯色（红/绿/黄） | 不回 |
| `03 03` | 保存 96B + 颜色到运行态 → 按 6 行 × 16B 渲染（固定 `FONT_16`，颜色 `[5]+1`） | `0x1B` |
| `04 04` | 更新字号/字型运行态 → 清屏 + 三行确认「字体设置 / 大小：xx点阵 / 类型：xx」 | 不回 |

- `03 03` 不写 W25Qxx；保存后成为本上电周期内「总显示时间到期」恢复的画面。
- `04 04` 的越界半字节保持原值（与旧固件逐半字节独立判断一致）。

### 2.7 默认开机画面

**本模块不注册任何默认画面**（原广西专属「欢迎行驶 / 广西高速公路 / 祝您旅途愉快!」三行黄字及
`app_gx_proto_default.c` 已删除）：

- 上电阶段 `sw_initcall` 只做注册五步（§2.2），**不调用 `app_default_display_register`**
  ⇒ `app_boot` 末尾的 `app_default_display()` 显示项目通用默认画面
  「欢迎行驶 / 高速公路」（`FONT_SELF_ADAPT` / `FONT_HT` / 黄色居中，见 `app_default_display.c`）。
- 本上电周期收到 `03 03` 后，该界面成为总显示时间到期（§2.4）的恢复画面；
  从未收到时到期恢复项目通用默认画面（`app_default_display_show()`）。
- 无显示构建不渲染、零告警（渲染入口先判 `dev_display_get()`）。

### 2.8 无显示构建

所有渲染/亮度入口先判 `dev_display_get()`；无显示时安全跳过（不使用 `dev_display_guard` 打日志——
业务代码禁止 RTT）。串口、IO、语音、应答照常工作。

## §3 probe 判据与同槽共存

### 3.1 判定链（PURE：只 `rb_peek` / `rb_peekc`）

| 步骤 | 条件 | 返回 |
|---|---|---|
| 1 | `avail == 0` | FAKE（禁止盲 WAIT） |
| 2 | `[0] != 0xAA` | FAKE |
| 3 | `avail < 3` | WAIT |
| 4 | `[2] != 0xBB` | FAKE |
| 5 | `avail < 5` | WAIT |
| 6 | `{cmd1,cmd2}` 不在 8 组白名单 | FAKE |
| 7 | 按命令码定界（见 §3.2） | READY / SKIP / WAIT / FAKE |

**输出参数**：READY 与 SKIP 写 `*total_len`（框架的 SKIP 分支同样消费 `frame_len`）；
WAIT / FAKE **不写**。

### 3.2 定界

| 命令 | 判据 |
|---|---|
| `51 54` | `avail ≥ 12`；从 `[11]` 扫到 `min(avail-1, 203)` 找 `0xFF`；找到 → 帧长 = 下标 + 1（颜色码 >2 时 SKIP）；未找到且 `avail < 204` → WAIT；`avail ≥ 204` 仍无 → FAKE |
| `4B 4C` | 7B；`[5] > 3` → SKIP |
| `4B 5A` | 8B；三元组未知 → SKIP |
| `56 4F` | `[5] == 0` → 8B（编号 1~5 否则 SKIP）；`[5] == 1` → 14B（金额非 ASCII 数字则 SKIP）；其它子命令 → FAKE（长度不可定） |
| `01 01` | 7B；`[5] != [6]` 或 >2 → SKIP |
| `02 02` | 5B |
| `03 03` | 103B；颜色 >2 → SKIP；末字节非 `0xFF` → FAKE（可能是错位残帧，交 1 字节重同步） |
| `04 04` | 6B |

### 3.3 同槽共存

`0xAA` 在 RS485 / RS232 / RJ45 三槽对现有协议均唯一（现有首字节：`0x7B` / `0x0A` / `0x5A` /
`0x54` / `0xFF` / `0x5A5A5A5A` / `0xFFFF`）⇒ **不需要 EIDE 目录互斥、不定义 `g_brace_proto_guard`**。
本协议可在任意现有协议集合中同编。

## §4 内存与队列

### 4.1 CCMRAM（实测 2056B）

| 对象 | 定义 | 字节 |
|---|---|---|
| 队列体 | `s_gx_queue_buf[3 × 212]` | 636 |
| `StaticQueue_t` | `s_gx_queue_cb` | 80 |
| 任务帧缓冲 | `msg_buf[212]`（任务内 static） | 212 |
| 任务栈 | `PL_TASK_STATIC_STORAGE(gx_handle, 256)` = 1KB | 1024 |
| `StaticTask_t` | 同上宏 | 100 |
| 对齐 | | 4 |
| 合计 | | **2056** |

`GX_MSG_SIZE = sizeof(frame_msg_t) + 204 = 212`；队列深度 3（与新疆/云南治超同量级）。

**实测增量**（EIDE 官方 builder，临时 params 输出到仓库外；同一 `Debug` 选择集 ± 本模块 4 文件，
A/B 双构建）：`.text +4824` / `.rodata +464` / `.data +8` / **`.ccmram +2056`** / `.bss +128`；
SRAM 合计 +136B（`._user_heap_stack` 不变）。

> 该轮 4 文件口径包含**现已删除**的 `app_gx_proto_default.c`（默认画面文案/渲染 ~0.2KB 量级），
> 故现行 3 文件口径的 `.text` / `.rodata` 增量略小于上表；`.ccmram` / `.bss` 与默认画面无关、不受影响。
> 本轮删除实测（同一 `Debug` 选择集，del 前后双构建）：`.text **−304**` / `.rodata **−80**`，
> `.data` / `.bss` / `.ccmram` / `._user_heap_stack` 逐字节不变。

### 4.2 SRAM

- 模块状态：`mask × 2`（16B）+ 队列句柄 + 定时状态 + 字号/字型 + 颜色 + 开机界面缓存
  （96B + 颜色 + 有效标志）≈ **128B bss + 8B data**（实测）。
- 自备 RS485/RS232 RB 体：**1536B**（仅当没有其它串口协议提供同槽体时实际占用；
  多协议构建下 weak 合并为 0）。
- 只读查表（字号/字型/文案）落 `.rodata`（已计入上方 +464）。

> 实测口径 = 该轮 `Debug` 选择集（207 源 + 本模块 4 源，含现已删除的 `app_gx_proto_default.c`；
> 显示驱动 `dev_display_1_263.c`）。
> 模块增量与显示驱动无关；广西量产换成 `dev_display_1_969.c` 后应按链接期总量复核。
> 预估：当前非显示部分 CCM 用量 14764B + `1_969` 驱动 38208B + 本模块 2056B ≈ **55028B**
> （余约 10.5KB），以 Rebuild 实测为准。

3. 其它协议目录按需：广西量产建议保持 `ldi` / 重庆 / 缅甸 / RLS / AH 排除；
   需要与四川三共存调试时可保留；
4. 不定义 `PROTO_CHONGQING`、不定义 `STD_ALL_PROTO`（本协议不是 `{` 帧族）；
5. 构建后看 `.ccmram ≤ 65536`、`.data + .bss + ._user_heap_stack ≤ 131072`，
   告警只允许 3 条既有 HAL `-Wunused-parameter`。

详见 `doc/构建开关总表.md` §7.2 第 11 条。

## §7 已知限制与待联调项

1. **播放方式 1~21 未实现**：全部按直接显示处理（与旧固件现场行为一致）；速度/停留忽略。
   后续若接 `app_scroll`，注意其文本上限 64B（本协议 192B 会被截断）。
2. **校验和不校验**：联调抓到真实帧后，可用 `gx_sum_calc()` 核对上位机算法，再决定是否启用；
   算法差异会导致「全丢帧」，故 v1 保持放行。
3. **地址不判**：多机共总线现场需把 `GX_LOCAL_ADDR` 设为 1~254（0 = 不判）。
4. **`03 03` 不持久化**：掉电回项目通用默认画面（「欢迎行驶 / 高速公路」）；如需持久化要另占 W25Qxx 扇区（未实施）。
5. **`04 04` 无文档依据**：语义完全按旧固件移植（低/高半字节）；文档不存在该命令。
6. **收费语音小数**：`1.50` 会念成「一点五零」（`%02u`），现场听感需确认；
   `1.00` 只念整数。
7. **不设置语音音量**：沿用语音板上次档位。
8. **无 RTT 诊断**：业务代码零 `SEGGER_RTT_*` 调用；现场判读靠屏体/灯板/万用表 + 调试器断点。
9. **`02 02` 版本串**：显示 `版本:PROGRAM_CODE`（`9K1F3127E2`），不保留旧固件的
   「广西P5费显V1-192x96-2025.10.16」（会随硬件/日期漂移）。
