### 03_freertos_heap_side_effect.md（[已归档] 副作用归档，FULL）

- 现象：上电进入 `vApplicationMallocFailedHook`——`tcp_server_task → osSemaphoreNew → pvPortMalloc 失败`；当时堆约 36KB@SRAM，多协议任务栈叠满后在 TCP Server 起步处击穿。
